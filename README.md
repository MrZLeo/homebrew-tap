# Mrzleo Tap

## How do I install these formulae?

`brew install mrzleo/tap/<formula>`

Or `brew tap mrzleo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mrzleo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
